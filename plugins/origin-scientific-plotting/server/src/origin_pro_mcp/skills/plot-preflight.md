# 绘图前方案与数据格式核验

## 验证基线
- 已验证：Origin 2020（上游历史验证；具体工作流见本 skill 内文）；Origin 2026 / Origin64.exe 10.3.0.180：工作表读写、line+symbol 图、出版样式、PNG 导出（2026-11-10）
- 未验证：其他 Origin 版本；复杂误差棒、全部图形类型、质谱/分组/批量工作流（详见 UPGRADE-STATUS.md）

## When To Use
每次使用 Origin 创建新图、批量绘图或依据参考图重绘前使用；Excel 导入后绘图也必须执行。

## 先整理完整方案
在创建图之前，结合用户指示、源数据和软件实际能力形成可执行方案；复杂任务可向用户简要展示主要选择，用户已授权且选择清楚时直接执行，不为常规步骤额外等待确认。若图型、列含义、误差含义、处理方式等会改变科学结论的信息缺失，先读取可用资料；仍无法确定时只问必要问题，独立部分可先完成。

方案至少明确：
- 图的数量及名称、图型、用途、参考样式、各图独立窗口或组合方式；每图来源的文件、工作簿、工作表、行范围与列范围。
- 各列角色（X、Y、分类/组别、处理、重复、误差、颜色或 Z），长表/宽表、观测单位、组别及排序；单位、标题行、数据行、缺失、异常值、公式缓存与日期等特殊数据。
- 用户要求的统计处理、误差定义、是否已有汇总值、重复数及排除规则；不把汇总值冒充原始重复，不推断 SD、SEM 或显著性，除用户明确指定的质谱绘图补零规则外，不擅自插值或填零。
- 源格式与目标图型是否匹配；明确需要的重排、分组、统计、数据副本、列类型和目标存放位置。保留原始 Excel 和原始观测，尊重工作表数量和是否允许新增窗口的要求。
- 操作顺序：导入与对照核验 → 必要的数据整理和再次核验 → 设定列角色/分组 → 试绘一张并检查 → 需要时批量 → 验证数据、样式和导出 → 保存可编辑项目。说明图例、字体、坐标范围与误差棒检查、输出路径及不会覆盖的方式。

## 数据格式适配规则
- 折线/散点：X/Y 值配对且行对齐；折线还需确认 X 有合理的连续顺序。多条曲线明确各自 X/Y 的对应关系。质谱峰表先加载 mass-spectrum：符合用户指定条件的筛选后离散 m/z 数据，在绘图副本按 0.1 补网格、新增强度填 0 后再绘图。
- 分组柱形图：分组与处理标签、每组数值及误差一一对应；区分原始重复和均值±误差。每个指标限用对应行，不能因数据共用一表就绘入全部指标。
- 箱线图与分布图：需可用的原始观测或明确支持的分布统计，不能直接把均值及误差当原始样本；直方图核对频数、密度和分箱。
- 热图/等高线/曲面：确认规则矩阵或 XYZ 数据及其单位、网格、重复点和缺失；如需插值，说明方法与参数，不把插值称作观测。
- 双 Y 轴：确认每条系列对应的坐标轴、量纲与独立范围，检查视觉比例不会误导。

Excel 导入按 excel-to-origin：导入前检查源格式与目标图型，导入后再次对照和验证能否正确映射。开发版可用 `preview_excel_range` 与 `import_excel_range` 指定数值型 .xlsx/.xlsm 工作表和矩形区域；旧 `import_data` 不提供工作表/区域选择，不得假定已选择。若格式不匹配，先在用户授权范围内整理成可追溯的数据副本，保留映射与原始值；无法安全转换或科学含义不明时停在该步骤并说明。用户未明确指定图型时，结合数据结构与研究目的选合适图型；影响科学解释的选择需说明或询问。

## 出图前门槛和出图后核验
实际读取数据、检查来源与列映射、完成必要整理并复核后才调用绘图工具。模板或绘图脚本的输出要验证数据范围、样本数、顺序、各组处理、误差棒、单位、标题、图例与视觉样式；核验第一张后再批量处理，完成后抽查其余图并保存原生可编辑结果。工具返回成功不等于图形正确；报告异常与未验证部分。
