# 质谱折线图：稀疏 m/z 补零

## When To Use
使用离散或筛选后的 m/z 与强度表绘制质谱折线图，特别是相邻 m/z 有明显跨度时使用。

## 绘图前检查
先按 plot-preflight 识别 m/z 列、强度列、单位、数据类型、仪器输出类型、观测范围、排序、间距与峰是否已筛选；Excel 来源还需按 excel-to-origin 校验导入。不能仅凭间隔大就断言这些点是实测零；判断筛选后稀疏数据时，可结合表格描述、源文件和峰列表结构。完整的 profile 原始谱、真实连续信号、非均匀采样或明确缺测的数据，不得套用此补零规则。

## 用户指定的默认处理
当数据明显是筛选后的离散质谱峰表、m/z 能够匹配 0.1 网格，且目标是质谱折线图时，绘图之前在可追溯的数据副本中补齐相邻 m/z 之间的 0.1 网格点，所有新增点的强度设为 0；原始点的 m/z 和强度逐一原样保留。默认只填实际观测 m/z 最小值至最大值之间，不向两端任意延伸。例如 100.0 与 100.3 之间补 100.1、100.2，其强度均为 0。再按 m/z 升序绘制折线图，避免跨缺失区直接连线造成误导性宽峰。多组谱应各自补齐并核验，保留组别对应关系。

生成网格时使用十进制或整数 0.1 单位索引，避免浮点误差导致漏点或重复；允许为浮点表示误差设置极小容差，但不得为了适配网格把高精度 m/z 强行四舍五入或合并峰。若 m/z 不在 0.1 网格、存在重复 m/z、多重峰、高分辨率测量或谱型不确定，保留原始数据并确认适当处理方式，不自行覆盖、聚合或丢弃峰。现有数值中的空白/缺测不能一概变为零：该规则仅填新增的网格点，原有缺失值按来源处理。

## 核验和表达
验证全部原始 m/z 与强度完整保留、每个新增点为 0、排序正确、网格步长为 0.1，并检查峰数、峰位置、峰高及作图范围；查看导出的峰形与图例后保存原生 Origin 项目。记录新增零值是为绘图构造的基线假设，而非仪器直接测得的强度，也不能据此重建真实峰宽或原始 profile。不要修改原表；按用户对 sheet 数量的限制放置绘图副本。用户明确指定其他步长或不补零时优先遵从。
