# 两处理分组柱形图与误差棒

## When To Use
当多个指标各有若干分组、每组两个处理及对应误差，需要绘制可编辑 Origin 柱形图时使用。

## 会话与核对
先加载 plot-preflight，整理目标图、来源、格式、行列映射、转换、绘图及验证的完整步骤，并确认格式适合分组柱形图。先确定目标是现有窗口还是独立会话。默认隔离会新建独立 Origin；不能把该会话误认为手动打开的项目。明确要求现有窗口时，使用专门配置的 attach 会话；调用 list_worksheets 并核对项目、工作簿、工作表以及现有图名。ApplicationSI 不能保证在多个窗口中选中指定窗口，未核对身份前禁止修改。禁止加载项目覆盖有未保存修改的会话；连接错误时不要自动创建新窗口继续操作。

读取数据并核对处理标签、单位、分组及误差列含义。若源为重复观测，只有明确统计需求后才计算均值和 SD/SEM；不知道误差含义则询问，不得猜测。单个绘图数据表可按指标连续排列：指标名、分组 X、处理 1 均值、处理 1 误差、处理 2 均值、处理 2 误差。例如本次为三组 CON、LE、LP；24 行代表八个指标。每个指标使用对应三行，不能将全部 24 行绘入同一指标。

## 绘图策略
优先使用 Origin 原生分组柱图或已验证的分组柱图模板，数据映射为 X、Y1、YErr1、Y2、YErr2，确保并排而非重叠，六根柱各自带正确误差棒。创建每个图时限定各自的行范围；现有 create_graph/add_plot_to_graph 接口未暴露行范围，不能假定它们会自动按指标筛选；可先用临时数据范围或经验证的模板/Origin 界面，禁止擅自改动源数据。不同指标共用一个工作表即可，不必新建多个 sheet。每张图独立保留单位、纵轴范围和指标名称，并在项目管理器注释填入名称。绘图按钮若产生嵌入图，检查当前绘图位置设置，目标为独立图窗口时显式选择新图窗口。

本次参考配色：处理 +pro 为 RGB(160,0,0)，No pro 为 RGB(3,78,97)；仅在用户要求沿用时使用。字体、字号、柱宽及间距以用户最新调整的图为准，图例按要求放在绘图区下方并避免遮挡。复制格式时先试一张，验证目标数据、误差棒、坐标范围、轴标题和图注；不要复制源指标的轴范围或文字。图例位置、字体以及分组间距应在实际图中核验，不以工具成功作为完成依据。注意现有 ungroup_plots 仅支持线和散点重绘，不适合柱图。

## 效率与验证
可用模板复用经过验证的外观，但先确认模板保留两个处理及误差棒、正确使用目标数据和量程；首次先做一张并检查，成功后批量。对每图核对三组、六柱、两组颜色、误差棒、数据范围、单位及图例；另存可编辑项目并检查预览。涉及格式复制、行范围、图例置底的具体脚本在此插件尚未通过本次实例的自动化验证，应以实际版本的结果为准，不得宣称已经自动完成。
