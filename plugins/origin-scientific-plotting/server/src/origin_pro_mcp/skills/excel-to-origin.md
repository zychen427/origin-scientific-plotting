# Excel 数据导入 Origin 工作流程

## When To Use
需要把 Excel 工作簿数据导入本机 Origin，核对表格、指定 X/Y/误差列并绘图时使用。

## 导入前：来源与目标
1. 先调用 list_skills、get_skill("excel-to-origin")、get_skill("plot-preflight")；在导入前明确目标图型及所需的数据结构，导入前后检查数据格式是否匹配；确认源文件路径、目标 Origin 会话和用户是否要求当前窗口。不得因连接失败自动另开会话或加载项目覆盖当前工作。查看 list_worksheets，核实活动项目、已有工作簿和未保存工作。
2. 只读检查 Excel 的工作表名称、隐藏状态、使用区域、标题和单位行、合并单元格、日期、分类文本、公式及缓存值；确认需要哪一张表或区域、是否保留其他表、列的实际含义。用户已指定时遵从，不要把所有工作表当成同一数据集。不要修改源 Excel；源表重复观测值、缺失值及处理组标签均需保留。
3. 公式单元格需区分公式、缓存值与 Excel 显示值；缓存过期或缺失时不要声称已重新计算。日期与单位要核对；错误值、空值、文本和零不能互相替换。必要时征询对科学解释有影响的信息，不能自行猜 SD/SEM、单位或排除规则。

## 使用 MCP 导入
- 对常规 .xls/.xlsx/.xlsm 文件，调用 import_data(file_path=完整路径, format="excel", book_name=可选名称)。现有接口没有 sheet、单元格区域、标题行、公式重算参数；不能声称它只导入了指定工作表。当前工具先创建独立 Origin 工作簿再导入，保护活动工作簿；导入后必须根据返回 name 和 list_worksheets 确认实际结果，不能假定图、工作表或名称。
- 如果只要某一 sheet/区域，先在工作目录生成**只含目标数据的临时副本**，不修改原文件，再用 MCP 导入；保留原始表的文本、空值、单位与数据顺序。不能把 set_worksheet_data 当作通用混合数据导入器：它只接受数值和缺失值。不能擅自创建很多工作表；按用户的目标结构组织。
- Excel 多 sheet 的导入数量、名称、表头位置和格式受 Origin 版本及导入设置影响，逐次回查。2026 版的一次合成测试中，两个 sheet 均被导入，首行列名保留在数据行，空单元格读回为空字符串；这不是所有文件/设置的保证。

## 导入后核验与绘图
1. 调用 list_worksheets 和 get_worksheet_data 读取实际表。对照 Excel 源表核对 sheet、行列数、标题位置、文本、数字、日期、空单元格、公式结果、单位和首末及抽样数据；重要数据必要时逐格核对。Origin 导入成功不等于数据正确；表头是数据行时，应先根据实际情况处理，不能把它当作数值观测。源为空白时不能自动填零。
2. 按 plot-preflight 整理图型、数据映射、必要整理、作图及核验的完整步骤；格式不匹配时先保留源数据并整理可追溯副本。明确 X、Y、分类和误差棒列后使用 manage_columns 设置列类型；重复值与统计汇总需按用户要求处理。现有按列绘图接口没有限定行范围的参数；按指标作图前先构造可核实的范围或数据副本。
3. 绘图时加载 plot-recipes 或 grouped-column；默认 Times New Roman，用户指定优先。检查图例、坐标、误差棒与数据对应关系，导出预览并保存可编辑 Origin 项目到授权位置。完成后主动核验并报告异常与未覆盖的特殊情况。

## 故障处理
导入失败可能留下部分导入的新工作簿；先查看实际状态再决定处理，不自动重试或删除。不要为跳过对话框盲目点击确认；不能把 COM 拒绝访问直接归因于注册错误。安全检查包括已有工作簿未受改动及源 Excel 未被写入。
